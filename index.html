Synk till GitHub

Hur skapar jag token?

1. Skapa ett privat repo för datan (bocka i "Add a README").
2. GitHub → Settings → Developer settings → Fine-grained tokens.
3. Repository access → Only select repositories → välj datarepot (inte förvalet "Public repositories").
4. Permissions → Contents → Read and write (förvalet är Read-only).
5. Skapa, kopiera nyckeln, klistra in ovan. Nyckeln sparas bara här på enheten.

Säkerhetskopia

All data finns alltid lokalt på enheten. Exporten är ett extra skyddsnät.

Om beräkningen

Ägglossningen är beräknad ur dina mensstarter, inte uppmätt: appen lägger den 14 dygn före nästa mens (lutealfasen är den konstanta delen av cykeln). Utan LH-test eller temperatur finns ingen mätning, så den ägglossningsdag som visas är en skattning. "Dagar till mens"-vyn fångar premenstruella mönster bäst, eftersom cykellängden mest varierar före ägglossning. Mönster blir tillförlitliga först efter ~3 fullständiga cykler.
